## GitHub Pages

This is a static site, so it can be hosted directly with GitHub Pages.

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**.
4. Save.

After GitHub finishes publishing, the Pages URL will be shown in the Pages settings.

## Customize

- Edit `index.html` for content, ranks, lore and social links.
- Edit `style.css` for colors, layout and visual effects.
- Edit `script.js` for interactions.
- Replace the gallery placeholder cards with your own GTA V RP screenshots.
